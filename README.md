# Python Basics — NumPy & Pandas

Beginner-friendly scripts covering fundamental operations.

## Files
- `numpy_basic_operations.py` — arrays, math, stats, slicing, reshaping, random
- `pandas_basic_operations.py` — DataFrames, filtering, groupby, missing data, CSV I/O

## Setup
```bash
pip install numpy pandas
```

## Run
```bash
python numpy_basic_operations.py
python pandas_basic_operations.py
```

Each script prints labeled sections so you can follow along and tweak values.
